# 轉文字（iOS / iPadOS）

上課、對談錄音即時轉成繁體中文字稿的 App。錄音和轉文字都在裝置上做（Apple SpeechTranscriber；可選 WhisperKit 在下課後再轉一份），另有：

- 照課表自動命名錄音（課表放在裝置上的設定檔，見下面）
- 錄音中照課程對照表即時改字（只改畫面，存檔的稿是原字）
- 可選：錄音中把稿的字送 Claude Haiku 改字（要自己的 Anthropic API 金鑰，存在裝置鑰匙圈；錄音本身不送）
- 可選：停止後把「匯出（不含錄音）」那包傳到自己的 Google 雲端硬碟
- 離線分人（FluidAudio）、連電腦版當麥克風、引擎比較的實驗模式

- v0.28.0（進行中）：點逐字稿一行改字的畫面分兩格——上格是這一行的字（進逐字稿），下格「跟 AI 說」（不進逐字稿、不進 md／PDF／整理版，存在卡片.json；只寫下格不改字也能存），之後每批送 Haiku 時另列一段「使用者的說明」。改過的字送 Haiku 時說明改成：只有原稿裡出現一模一樣的原字才照改，發音相近的別的詞不套用，改字不代表這堂的主題（主題以使用者選的課名為準）。卡片提示詞：講者不一定是老師（看不出來寫「講者」或不寫主詞）；整段聽不清或只是現場口令、雜聲時，重點和整理版只寫「（這段聽不清）」或「（現場口令）」，不編內容，這種重點在畫面上淡化；擴寫式校正沒有證據（投影片、詞表、Apple 同一段、上下文）就保留原字、可列進不確定，不刪原稿的詞。
  - 逐字稿改了，重點卡跟著改：一張卡的逐字稿被改（點一行改字、只留「跟 AI 說」、重查改字、按重查的「套用」）之後，最後一次改動後等 4 秒，另送一個小的 Haiku 請求（不上網查），只帶課名、這張卡改好的逐字稿、這張卡的說明、原本的重點和整理版，照逐字稿重寫這張卡的重點和整理版（規則和卡片一樣，並明寫「逐字稿是準的，重點不得和逐字稿矛盾」）。同一張卡同時只送一個，送的時候又被改就跑完再送一次；重點下面有小轉圈「更新中」。花費算進這張卡和這場（含 1 美元上限），失敗就保持舊的；私人課程、沒金鑰、Haiku 關掉時照舊不送。停止錄音時排著的馬上送、補送期限內等它跑完（停止時沒網路就不等）；新的重點和整理版存進卡片.json，分享和 PDF 用新的。每次約 0.0003–0.0005 美元。
  - 重查：每次重查完（不論有沒有改字）都觸發上面的重算，重點會對齊逐字稿。卡上的重查預設收成一行（結論），點一下才展開為什麼、來源、已改、沒把握；PDF 照樣印完整。同時圈好幾次會排隊，一個一個查（卡上寫「排隊中」）。
  - 重查找到答案卻沒套用：提示詞改成「結論說要改的一定放進 fixes」；沒把握但有具體猜測的放新欄位 maybe（原字一樣要在圈起來的行裡找得到），卡上顯示「原字 → 猜測」和小的「套用」鈕，按了套進那一行（綠字）、標成已套用、觸發重算。以前寫在「沒把握」裡的改法會被丟掉，現在改列成可以按套用的猜測。「套用」只有錄音中能按；停止後的結果畫面只顯示。
  - 重查的來源：提示詞要求只列真的支持結論的網址（JSON 的 sources），程式只留搜尋結果或引用裡真的出現過的那些；沒有就不列，不再把全部搜尋結果都列上去。來源只在展開時顯示。
  - 重點是「（這段聽不清）」這類固定字樣時，重查不把它當成重點送出去；PDF 裡這種重點也不再用粗體大字。
  - Apple Pencil 圈選可以跨卡：以前每張卡各自記行的位置，一筆只算得到起筆那張卡；現在每行的位置記在整張卡片清單的座標，一筆圈過相鄰幾張卡的行就合成一次重查（行照時間接起來，重點用第一張卡的）。改法各自套回所屬那張卡的那一行；重查結果掛在圈到的第一張卡上，展開時寫「也涵蓋 mm:ss 那張卡」（PDF 同）；涉及的每張卡都重算重點。
  - 錄音被打斷後在背景接不回來（獨佔麥克風，錯誤碼 '!int'／'!pla'）：這場暫時改成和別的 App 共用再接一次，接回來記一行進 info.txt，之後維持共用到按停止（錄音中換回獨佔要重設聲音類別、可能又斷一次，所以不換）；下一場照開關重設。改了還是接不回來就改回獨佔，照原本的快速重試、看門狗走。【推論，還沒在真機驗】
  - 錄音中斷看得到：看門狗看到停了又接回來，存成一段（整場第幾秒斷、少了多久、牆上時間起訖，跟著場的 json 存）。停止後 transcript.txt 稿頭寫一行「錄音中斷：…」；卡片接成的逐字稿、逐字稿 md、重點 PDF 在那個錄音位置（卡和卡之間）插一行「〔錄音中斷 m:ss（HH:mm–HH:mm），這段沒錄到〕」。分好人的逐字稿、Apple 定稿的稿沒辦法插在字中間，只有稿頭那行；錄音畫面上的卡片沒有標；按停止時還沒接回來的那段不算（照舊只在停止那行寫少了多少）。
  - 錄音中才指定課名：以前指定之前已經轉出的字只在原文檔，沒進卡片和逐字稿；現在建審稿器時把這些字每 60 秒切一段補交（一段一張卡），排在之後的新字前面。
  - 錄音中才指定課名的場，檔名（匯出 zip、原始轉錄、錯誤資料、停止後的逐字稿 md 和重點 PDF）和自動上傳改用那時指定的課名，不再叫「未分類」、不再因為沒課名不傳；私人課程照樣用同一個課名擋。錄音檔和稿的資料夾照舊（不搬檔）。

- v0.29.1：非課程（其他場合）錄音中自動上網找「參照詞」。
  - 什麼時候搜：只有非課程、卡片模式（有重點卡的場）、Haiku 開著時。錄音秒數到 5 分鐘（續錄從整場開頭算；錄音中才改成非課程的，到了就搜）而且已經有 100 字以上，搜第一次。之後每 600 秒看最近 600 秒的稿：一個參照詞都沒出現（不分大小寫的子字串比對）、而且那段有 300 字以上，才重新搜（話題換了）；有出現就不搜。搜過之後改主題，最後一次改完 60 秒搜一次。一場最多 3 輪（拿到回應才算一輪）。
  - 送什麼：到目前為止的稿（全部卡：整理到的用改好的字、沒整理的用 Whisper 原字，加上還沒進卡的字；最後 6000 字）＋主題（有寫才送）；第二輪起附上已經找到的參照詞，叫 Haiku 只列新的或寫法要更正的（更正的把舊寫法拿掉）。**這比 Pencil 重查送得多（重查只送圈起來的幾行），而且 Haiku 會用稿裡的詞去搜尋；非課程開始前不跳提醒，在場的人要自己告知。**
  - 回什麼：最多 30 個參照詞（人名、書名、地名、機構、術語），每個附 24 字內的說明，和一句「這場大概在講什麼」。提示詞要求只列搜尋結果真的支持、稿裡講到的詞，不要猜。合併時新的在前、同一個詞新的蓋掉舊的、去重複、最多 30 個（太多丟最舊的）。Pencil 重查真的改進逐字稿的字也收進參照詞（不另外搜尋、不算輪數；判斷「最近的稿沒講到參照詞」時不算這些）。
  - 怎麼用：之後每張卡、每次重查、每次重算的使用者訊息多一段「網路查到的參照詞」（和主題同一個管道，不放進有快取的課程區塊；主題、參照詞、改字對照、使用者的說明各一段，不重複）。卡片提示詞：參照詞算改字的證據，但只有原稿的字和它發音相近、上下文也合才照它寫；說明不抄進 expanded、tidy、key。
  - 功能不重疊：和 Pencil 重查共用同一份上網的程式（請求、pause_turn、429／5xx 重試、花費），排同一個隊伍（不會同時查兩個；重查排在它後面時卡上寫「排隊中」）；狀態列同一行多「・參照詞搜尋中」或「・參照詞 N 個」，不另開橫幅。
  - 花費（自己的金鑰）：每輪最多搜尋 3 次（每次 0.01 美元）＋ token，推算每輪約 0.03–0.04 美元、一場 3 輪約 0.1 美元（還沒實測）。參照詞搜尋的花費另計（改字紀錄 `refCostUSD`），**不加進卡片的 1 美元上限**，所以搜尋不會讓卡片停；這場搜尋花到 0.20 美元就不再搜（每輪開始前看，最後一輪可能超過一點），卡片照常。錯誤資料的 Haiku 那行多「參照詞 N 個（搜尋 R 輪、約 X 美元另計）」，只寫個數。
  - 失敗：網路錯、沒網路、4xx（例如帳戶沒開網路搜尋）、回覆讀不出來都只記一行，卡片照常，下次 600 秒的檢查再試；沒拿到回應連續 3 次就這場不再搜。搜尋網路錯不像重查那樣一直等（免得卡住排在後面的重查）。停止錄音後不再搜，補送不等它。
  - 續錄：參照詞、說明那句、輪數、花費、上次檢查的時間存在改字紀錄（`refTerms`、`refAbout`、`refRounds`、`refFailures`、`refCostUSD`、`refLastCheck`），續錄讀回來接著用，不從頭搜。紀錄只寫字數、個數，不寫稿和詞。
  - 還沒做／沒驗：沒在真機跑過（沒驗搜尋結果準不準、參照詞有沒有讓卡片改對字、會不會把沒講的詞寫進去）。非卡片模式（模式 0、2）和有課名的場不搜。畫面上看不到參照詞清單（只有個數；匯出的 fixes.json 裡有）。

## 怎麼編

需要 macOS、Xcode 26（iOS 26 SDK）、[XcodeGen](https://github.com/yonaskolb/XcodeGen)。

```sh
xcodegen generate
xcodebuild -project LectureText.xcodeproj -scheme LectureText -configuration Release \
  -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath build \
  CODE_SIGNING_ALLOWED=NO build
```

套件：FluidAudio 0.18.2、argmax-oss-swift（WhisperKit）1.1.1，版本寫死在 `project.yml`。
不簽名編出來的 .app 要自己簽再裝（例如 Sideloadly）。`.github/workflows/build.yml` 是同一套流程的 GitHub Actions 版，結果推到 `build-out` 分支；**公開倉庫的 build-out 誰都下載得到**。

不用 Xcode 也能先跑純邏輯的測試（只用 Foundation）：在倉庫根目錄照 `.github/workflows/build.yml` 第一步那行 `swiftc … -o shape_check` 編，再跑 `./shape_check`（要編哪些檔只寫在那一行）。

Haiku 的提示詞正本在 `tools/haiku_prompt/`，改了要跑 `python tools/haiku_prompt/同步提示詞.py` 產生 `Sources/HaikuPromptText.swift`。

## 設定檔：課表與課程對照表

程式裡不寫任何課名。App 啟動、回到前景時讀 `轉文字/設定/轉文字設定.json`（「檔案」App › 我的 iPhone／iPad › 轉文字 › 設定）。
**沒有這個檔＝沒有課表**：錄音用時間命名、沒有課程對照表、沒有課可以送 Haiku 或自動上傳；其他功能照常。

例子（課名都是編的）：

```json
{
  "firstDay": "2026-02-23",
  "lastDay": "2026-06-21",
  "toleranceMinutes": 10,
  "courses": [
    {"name": "幾何", "formal": "解析幾何", "weekday": 3, "from": "08:00", "to": "09:50"},
    {"name": "幾何", "formal": "解析幾何", "weekday": 6, "from": "14:00", "to": "15:30"},
    {"name": "讀書會", "weekday": 5, "from": "18:00", "to": "19:30", "weeks": [1, 3, 5, 7]},
    {"name": "私人課", "weekday": 1, "from": "20:00", "to": "21:00", "private": true}
  ],
  "offDays": {"2026-03-18": [], "2026-03-14": ["幾何"]},
  "privateKeywords": ["私人"],
  "liveFix": {"解析幾何": [["像量", "向量"], ["飛靈", "非零"]]}
}
```

| 欄位 | 意思 |
| --- | --- |
| `firstDay` | 第 1 週的週一（yyyy-MM-dd）；`weeks` 從這天算。沒寫就不限開始日，`weeks` 的課不排 |
| `lastDay` | 課表最後一天，之後一律用時間命名；沒寫就不過期 |
| `toleranceMinutes` | 上課前後幾分鐘內按錄音都算這堂（預設 10） |
| `courses[].name` | 標題和資料夾用的簡稱。**改了就和舊錄音的資料夾對不上** |
| `courses[].formal` | 正式課名，用在匯出檔名、課程設定檔名、課程對照表的 key；沒寫＝和 `name` 一樣 |
| `courses[].weekday` | 1＝週一 … 7＝週日 |
| `courses[].from` / `to` | HH:mm |
| `courses[].weeks` | 只有這幾週上；沒寫是每週 |
| `courses[].private` | 私人課程：永遠不送 Haiku、不自動上傳、不出現在投影片選課 |
| `offDays` | 停課日：空陣列＝整天沒課，否則只有列出的簡稱停 |
| `privateKeywords` | 課名（簡稱或正式名）含這些字就當私人課程 |
| `liveFix` | 課程對照表：key 是正式課名，每條是 `[稿裡常見的錯, 正確]`，錄音中只改畫面 |

格式錯（星期不是 1–7、時間不是 HH:mm、日期不是 yyyy-MM-dd、對照表一條不是兩個字串）整份不套用，橫幅會講是哪裡錯。

**匯入方式**（擇一）：

1. 用「檔案」App 把 `轉文字設定.json` 放進 我的 iPhone／iPad › 轉文字 › 設定（沒有就新建「設定」資料夾），再回到 App。
2. 在「檔案」App 長按 `轉文字設定.json` › 分享 › 選「轉文字」（或在 App 裡按「選檔案」選它）。App 檢查過才存進上面那個位置並套用；檔名要是「轉文字設定」開頭的 .json。

## Google 雲端硬碟自動上傳（可選）

在 Google Cloud Console 建一個「iOS」類型的 OAuth 用戶端（Bundle ID 用 `com.lecturetext.LectureText`），把用戶端編號填進 `Sources/GoogleDriveConfig.swift`。iOS 用戶端沒有 client secret，編號本身不是密碼。只要求 `drive.file` 權限（只看得到 App 自己建的檔）。沒填就整個功能不動作。

## 資料去向

- 錄音、逐字稿、聲紋都在裝置的 App 文件夾，標成不進 iCloud 備份。
- 送 Haiku 的只有稿的文字（使用者打開、有金鑰、不是私人課程時）；錄音不送。
- 智慧校正查維基百科只送挑出來的詞，像私人姓名的詞程式會先擋下。
